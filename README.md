# 🚀 Tech Flight | Accenture Social Innovation Week

**Tech Flight** is a career discovery platform designed for school leavers. Instead of providing generic career advice, it uses **GenAI** and a human-centered design to help students "find their calling" in the technology sector.

Developed during the **Accenture Social Innovation Week**, this project explores the intersection of **Agentic AI**, **Agile methodologies**, and professional **Branding**.

## 🛠 The Tech Stack
This project bridges the gap between frontend design and backend AI logic:

* **Frontend:** HTML5, CSS3 (Accenture Brand Guidelines), JavaScript (ES6+).
* **Backend:** Python, Flask.
* **AI Integration:** GenAI via API, focused on Industry-Specific Prompt Engineering.
* **Environment:** Virtual Environments (venv), Pip for dependency management.

---

## 💡 Key Features & Learnings

### 🤖 Agentic AI & Prompt Engineering
We moved beyond basic chat interfaces. By designing **Agentic AI** workflows, the system analyzes user inputs (Education, Subjects, Personality Traits) to provide tailored career roadmaps.

### 🔄 Agile & Scrum Workflow
The project was managed using **Agile** principles:
- **Daily Stand-ups:** To align on progress and blockers.
- **Sprints:** Rapid development of the "Find My Calling" feature.
- **Collaborative Learning:** Using Git/GitHub for version control within a team environment.

### 🎨 Strategic Branding
I learned how branding impacts user trust. Using **Accenture’s** professional visual language (the signature purple and ">" symbol), we ensured the platform felt authoritative yet accessible.
